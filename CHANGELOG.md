# Changelog

## [0.1.1] — 2026-10-20

- Новые названия стилей: Штиль, Глубина, Закат, Течение, Прилив; стиль по макету дизайнера — @opiatolove
- В меню после входа больше нет «Войти через Яндекс» и «Вставить токен» — только «Выйти»
- Убран отладочный пункт меню, из-за которого приложение могло подвисать
- Окно обновления показывает только список изменений
- install.sh: закрывает и удаляет старую версию под именем YaNotch, вход и настройки переносятся сами

## [0.1.0] — 2026-10-16

Первый публичный релиз.

- «Моя волна» Яндекс Музыки прямо в нотче: обложка, трек, прогресс, лайк / дизлайк, назад / вперёд
- Вход по коду через ya.ru/device — без паролей в приложении
- Настроение, характер и язык волны из меню по правому клику
- Медиаклавиши, AirPods и Пункт управления
- Эквалайзер в свёрнутом нотче по реальному звуку
- Продолжает с того же трека и секунды после перезапуска
- Шесть стилей оформления: Классика, Impeccable, Taste, Emil, Конфетка, Дизайн
- Иконка Telegram в нотче при новых сообщениях (нужен Универсальный доступ)
- Проверка обновлений раз в сутки, обновления подписаны
- Нативное приложение на Swift: ~30–50 МБ памяти
