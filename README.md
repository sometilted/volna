# Volna

«Моя волна» Яндекс Музыки в нотче MacBook. Нативный Swift/SwiftUI, без Electron и WebView — около 30–50 МБ памяти.

> Неофициальный клиент. Не связан с Яндексом. Нужна подписка Яндекс Плюс.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/sometilted/volna/main/install.sh | bash
```

Скрипт кладёт Volna в «Программы» и запускает. Эта же команда обновляет уже установленную версию.
Дальше обновления приложение предлагает само раз в сутки.

Пароль не нужен: у администратора Volna встанет в «Программы», у обычного пользователя — в `~/Applications`
(в Launchpad и Spotlight находится так же), и обновления там тоже ставятся без пароля.
Если стояла бета-версия — скрипт её удалит, вход и настройки Volna перенесёт сама.

## Что умеет

- Наведи мышь на нотч — панель с обложкой, прогрессом (можно тянуть), дизлайк / назад / play / вперёд / лайк
- Правый клик — настроение, характер и язык волны, стиль оформления, автозапуск, вход / выход, обновления
- Медиаклавиши, AirPods, Пункт управления
- Продолжает с того же места после перезапуска
- При новых сообщениях в Telegram из нотча выезжает иконка (нужен Универсальный доступ; в Telegram включи «Счётчик на иконке», в системных уведомлениях Telegram — «Наклейка на значке»)

## Вход

«Войти через Яндекс» показывает код в нотче и открывает ya.ru/device — подтверждаешь в браузере, токен подхватывается сам.
Яндекс спросит доступ к Диску — это стандартные права приложения Музыки, Volna Диск не трогает.
Токен хранится в `~/Library/Application Support/Volna/token` (права 600).

## Сборка из исходников

Нужны Xcode Command Line Tools, macOS 13+.

```bash
bash scripts/dev-cert.sh   # один раз: локальный сертификат, чтобы доступы не слетали после пересборки
./build.sh && open Volna.app
```

Логи: `~/Library/Logs/Volna.log`.

## Оговорки

Работает через неофициальное API Яндекс Музыки и может сломаться при изменениях на их стороне.
